# たまごっち風アプリ 素材パック(16bitピクセルアート)

## フォルダ構成
- sprites/ キャラ19種(透過PNG・512x512・足元ラインで揃う)
- icons/ UIアイコン12種(透過)
- foods/ たべもの・飲みもの12種(透過)
- props/ 演出小物8種(透過)
- game/ ミニゲーム用スプライト11種(透過)…カード6枚+裏面・もぐら・巣穴・トンカチ・かご
- bg/ 背景3枚(1024x1024・透過なし)
- sheets/ 分割前のアイコン・食材・小物シート(参考)
- raw_originals/ 生成直後の元画像(白背景つき)
- _contact_sheet.png 全素材の目視一覧
- manifest.json 全素材の用途一覧(機械読み取り用)

## 命名規則
- pet_a = うす黄色(主人公)/ pet_b = みどり / pet_c = ピンク
- 状態: idle=標準, happy=うれしい, sad=かなしい, sleep=おねむ, eat=たべる, sick=びょうき, play=遊び中, dirty=きたない, angel=お別れ
- 進化: egg → baby → child → adult

## コーディングAIへの引き継ぎメモ
1. まず manifest.json を読み込ませる(どの画像をいつ出すか割付けしやすい)
2. キャラスプライトは全て512x512・足元が下端24pxの位置:背景画像に重ねると地面が揃う
3. bg/ は透過なし: cover/fit で敷いてスプライトを上に重ねる
4. アイコンは48〜96px表示推奨、そのまま縮小しても輪郭がつぶれにくい

## 注意
- すべて生成AIで作成したオリジナルデザイン(実在キャラとは無関係)

## 追加(ミニゲーム素材)
- game_card_tree→cloud→plane→sun→star→moon の6枚が「強さ順」(1→6)。
- 金づら・トンカチは もぐらたたき用、かごは おんぷキャッチ用。

## 追加(新種族4体・別コンセプト)
- pet_d=ネコ(三毛猫風・耳/しっぽで進化が分かる)
- pet_e=モモンガ(脇の飛膜とくるしっぽ)
- pet_f=うさぎ(長い耳とコットンテール)
- pet_g=アザラシ(背中の灰もよう3点)
- いずれも A とは別の生き物(色替えではない)。進化3段階あり・状態絵は idleのみ(B/C と同じ扱い)。
- たまご(pet_egg)は全種族共通のまま(孵化時に選択した種族になる)。
