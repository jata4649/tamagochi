# ふれんどっち(たまごっち風育成 Web アプリ)

ブラウザだけで遊べる、たまごっち風のペット育成アプリです。
HTML + CSS + Vanilla JS の静的サイトで、ビルドツールは使いません。

> 開発中(現在: **M0 土台** 完了)。遊び方・デプロイ手順は以降のマイルストーンで追記します。

## ローカルで起動する

`file://` で直接開くと `fetch` が失敗することがあるため、必ずローカルサーバ経由で開きます。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## ファイル構成

```
index.html        … 1ページだけ。画面はこの中で切り替える
css/style.css     … デザイン全部(色などの変数は :root)
js/main.js        … 初期化・ゲームループの入口
js/ui.js          … 画面描画・トースト
js/assets.js      … manifest 読み込み・assetPath・素材パス定数
js/strings.js     … UI 文言辞書(画面の文字列はすべてここ)
assets/           … 素材 ZIP の展開物(読み込み専用・編集禁止)
```

## 仕様メモ(仕様書に無い判断の記録)

| # | 内容 | 決定 |
|---|---|---|
| 1 | 仕様書 §3 のルートフォルダ名 `tamagotchi-app/` | リポジトリ直下をプロジェクトルートとした(GitHub Pages でそのまま公開できるため) |
| 2 | UI 文言辞書の置き場所 | `js/strings.js` に §9 の辞書をそのまま置き、各モジュールから import する |
| 3 | 辞書に無い文言 | 既定名「ふれんどくん」(`defaultName`)と年齢書式「○日○時間○分」(`ageFormat`)を辞書の末尾に追加 |
| 4 | 素材の実際の中身と仕様書の差異 | `bg/*.png` は実体が JPEG(1330×1182)、一覧画像は `_contact_sheet.png`。**ファイルは一切変更せず**そのまま参照する(ブラウザは中身で判別して表示できる)。ステージの縦横比は背景の実寸比 1330:1182 にし、`cover` + `center` で表示 |
| 5 | M0 のボタン動作 | 押すとアクション名をトースト表示するだけ(処理は M2 で実装) |
| 6 | モジュール形式 | ES Modules(`<script type="module">`)。ビルド不要でファイル分割できるため |
| 7 | アイコンの表示サイズ | ボタン内 48px、上部 alert 36px(高さのみ指定・幅は等比) |
