# ふれんどっち(たまごっち風育成 Web アプリ)

ブラウザだけで遊べる、たまごっち風のペット育成アプリです。
HTML + CSS + Vanilla JS の静的サイトで、ビルドツールは使いません。

> 開発中(現在: **M4 セーブ/オフライン** 完了)。遊び方・デプロイ手順は以降のマイルストーンで追記します。

## ローカルで起動する

`file://` で直接開くと `fetch` が失敗することがあるため、必ずローカルサーバ経由で開きます。

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

## ファイル構成

```
index.html        … 1ページだけ。画面はこの中で切り替える
css/style.css     … デザイン全部(色などの変数は :root)
js/main.js        … 初期化・ゲームループの入口
js/state.js       … セーブデータの形・ゲージ更新・状態判定・スプライト選択
js/lifecycle.js   … 孵化・進化・お別れの判定と TIME_SCALE
js/screens.js     … 全画面(タイトル・名前入力・お別れ)
js/actions.js     … 8つのボタンアクションの処理・食材データ
js/overlays.js    … オーバーレイ画面(食事選択・ステータス)
js/minigame.js    … ミニゲーム(ボールの飛ぶ方向当て)
js/ui.js          … 画面描画・トースト
js/effects.js     … 演出(zzz・うんち・B/C の補助表示など)
js/save.js        … localStorage の読み書き・型の補正
js/assets.js      … manifest 読み込み・assetPath・素材パス定数
js/strings.js     … UI 文言辞書(画面の文字列はすべてここ)
assets/           … 素材 ZIP の展開物(読み込み専用・編集禁止)
```

| 30 | 進化の時間と TIME_SCALE | §4.1 の表の「デモ速 / リアル」をそのままモード別の表にした(たまご 3分/1時間、ベビー 3時間/24時間、こども 6時間/48時間)。`TIME_SCALE` の値はどちらの表を使うかの切替として使う。DevTools で `tt.setTimeScale(tt.TIME_SCALE.REALISTIC)` で切替可(保存はしない) |
| 31 | 表の「演出」欄の解釈 | 表の文言が1行ずれていると判断し、孵化時に「たまごが かえた!」、こども化に「こどもに なった!」(辞書に追加)、おとな化に「大人になった!」を出す。進化のたびに §5.4 の `prop_star` を5回出す |
| 32 | 孵化までの残り時間 | タイトル画面に「あと○分でうまれるよ」(1分を切ったら「もうすぐ うまれるよ」)。たまご中はタイトル画面のまま |
| 33 | 名前入力 | 孵化後、名前が未設定ならメイン画面の上に入力画面を出す(最大8文字)。空のまま決定すると「ふれんどくん」 |

| 35 | お別れ画面のスプライト | 仕様どおり色に関係なく `pet_a_adult_angel`(B/C の色合わせは M5 のオプション) |
| 36 | オフライン 24時間超 | 24時間を超えた分は「時間が止まっていた」扱いにし、段階の起点・ゼロ継続・うんち予約の時刻もその分ずらす(年齢は実時間のまま) |
| 37 | リセット | 「あたらしいたまご」でセーブ(`tt_save_v1`)を削除してタイトルへ戻る |
| 38 | セーブのタイミング | 新規開始・名前決定・各アクション後(食事選択やおふろの完了時、ミニゲームの各ラウンドも含む)・進化/お別れ時・1分ごと・ページ非表示時(`visibilitychange` / `pagehide`) |
| 39 | 読み込み時の補正 | 数値項目は `Number()` で数値化し、欠けた項目は初期値で補う。JSON が壊れているときと `version` が 1 より新しいときは新規開始(壊れているときはコンソールに理由を1行出す) |
| 40 | オフライン中の孵化 | たまご中に離れて孵化時刻を過ぎていたら、戻ったときに孵化済み(名前入力から)になる |
